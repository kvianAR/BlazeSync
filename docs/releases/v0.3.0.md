# BlazeSync — first public release

A macOS desktop file manager compatible with **Backblaze B2 Cloud Storage**.

- File/folder browsing, recursive folder sizes and complete folder downloads.
- Drag-and-drop uploads in the app and menu-bar panel/icon.
- Progress, speed and approximate remaining time.
- Separate current files and retained version/deletion history.
- Confirmed version-aware deletion, restore and one-way folder backups.
- Locked encrypted connection settings and light/dark themes.
- A minimal menu-bar app that stays out of the Dock.

## Install

Download **BlazeSync-macos-arm64.zip**, verify it against **SHA256SUMS.txt**, unzip and move BlazeSync.app to Applications or ~/Applications. Quit an older running instance before replacing it. Terminal installation instructions are in the repository README.

**Platform:** Apple Silicon (`arm64`); the app declares macOS 13 or newer. This local build is signed but not Apple-notarized. Review macOS Privacy & Security if it blocks opening; do not disable platform security globally.

## Validation and boundaries

The existing app passed 56 unit/regression tests and 45 packaged-desktop checks before public repository preparation. Installer regressions are included in the source suite. Desktop cloud workflows use a synthetic S3 fixture; live checks were read-only. Permanent live deletion and broad multi-GB/outage/sleep scenarios remain unverified.

No restart-resumable transfers, two-way sync, Finder mounting, client-side encryption, cloud rename/move or automatic photo thumbnails yet. Backup detection uses size/time rather than content hashes. Backblaze bills your account directly.

BlazeSync is independent and is not endorsed by Backblaze. See the README, B2 setup guide and troubleshooting notes before relying on important backups.
