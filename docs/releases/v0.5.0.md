# BlazeSync 0.5.0

## Folder sync

- Link a local folder to its B2 destination from Folder sync & backups using Add folder sync.
- Upload new and changed files immediately, then check every five minutes while BlazeSync is running.
- Use Sync now for a manual check and Open local folder to find the linked folder on your Mac.
- Compare content hashes to detect same-name, same-size code changes and skip unchanged content.
- Verify older uploads by reading their pinned cloud versions. Reuse verified immutable-version hashes during the session to reduce repeated downloads.
- Preserve empty folders and reuse the current cloud folder when its name matches the selected local folder.

## Duplicate choices

Manual sync and repeated uploads offer Cancel, Merge updates or Keep both when existing names are found. Merge updates skips unchanged content and uploads changed files to the same destination. Keep both creates separately named file copies. Linked sync jobs remember the copy destinations for future updates.

Scheduled sync merges local updates using the configured destinations. Sync operates from your Mac to B2. Historical versions remain governed by your bucket's retention and lifecycle rules.

## Finder

Enable Finder sync in the app to install the Sync with BlazeSync Quick Action. Right-click a local folder and look under Services or Quick Actions. The first use asks to link it to the current BlazeSync upload destination. Later uses run the saved folder sync. Refresh Finder sync after moving the app to another location.

Validated with 87 unit/regression tests, 56 packaged desktop checks using a synthetic S3 fixture, and an Automator workflow execution check with folder paths containing spaces. The Finder service was installed and confirmed in the macOS service registry.
