# BlazeSync 0.4.0

## Storage and billing

- Scan current files, retained versions and unfinished multipart uploads across accessible buckets.
- Apply the first 10 decimal GB free once per account.
- Project USD storage charges using Backblaze B2 Fundamentals pricing of $6.95 per decimal TB per 30 days, verified November 3, 2026.
- Display coverage limits for restricted keys or incomplete scans, bucket breakdowns, refresh controls and a locally saved budget alert.
- Open official pricing and the Backblaze dashboard from the app.

The projection assumes the scanned amount stays constant for 30 days. Actual invoices use byte-hours and can include additional usage charges, taxes or account-specific terms. The published rate is a dated snapshot. Refresh usage after external cloud changes.

## File management

- Multi-select files and folders for bulk download, move and deletion.
- Rename individual files or folders and preserve nested download structures.
- Confirm destination overwrites for uploads and moves.
- Verify copied destinations before removing move sources, reject overlapping source destinations and report partial failures.

Ordinary deletion and moves can retain historical B2 versions that continue using storage. Concurrent cloud changes can produce a partial move. Verified destination copies are preserved on failures.

## Installation and verification

Download BlazeSync-macos-arm64.zip and verify SHA256SUMS.txt. Quit BlazeSync, then replace your existing app. The terminal installer in the README also updates the same app location.

Apple Silicon macOS build, locally signed. Apple notarization remains pending.

Validated with 75 unit/regression tests, 50 packaged desktop checks against a synthetic S3 fixture and temporary mock keychain, a production build and dependency audit with zero reported vulnerabilities. Live cloud mutations, saved-key access after installation and invoice reconciliation require user verification.
