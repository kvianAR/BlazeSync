# BlazeSync 0.5.2

- Explain Backblaze account-cap errors that previously appeared as UnknownError during upload or folder-sync file checks.
- Diagnose opaque HTTP 403 HEAD responses with a bounded one-byte request and briefly cache the diagnosed reason.
- Show an account-limit banner with a shortcut to the official Backblaze Caps & Alerts page.
- Preserve the saved connection when an account bandwidth or transaction cap is reached.
- Clear the limit banner after a successful cloud read and allow sync to recover after the provider limit is lifted.
- Preserve the cap explanation for deletion errors.

Review account limits in Backblaze when this message appears, then retry the operation. Storage allowance and bandwidth/transaction caps are separate account settings.

Validated with 101 automated tests and 64 desktop checks against a synthetic S3 fixture. Live read-only diagnostics confirmed that listing and key authorization succeeded while file checks and reads were rejected by the account's bandwidth/Class B cap. Cap-denial and recovery paths are covered by the desktop suite.
