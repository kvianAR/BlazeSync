# BlazeSync 0.5.1

## Reliability fixes

- Handle same-name files selected from different local folders with an explicit duplicate choice. Merge uses the final selected source once. Keep both preserves separate contents.
- Preserve an unchanged final source when several selected paths resolve to the same cloud name.
- Reject copy-name collisions before any upload is queued.
- Detect replaced or symbolic-link sync roots and report an error while preserving the previous successful-sync timestamp.
- Serialize legacy delete, folder delete, permanent purge, restore and folder creation with other file-management operations.
- Block restore when an upload is writing to the same target.
- Reject operations confirmed after the connection changes.
- Reject stale billing results after an account change and clear their progress indicator safely.
- Add a startup syntax check for every Electron and packaging entry point.
- Keep Finder integration tests valid whether the Quick Action is already installed or absent.

## Verification

93 automated tests and 62 desktop checks cover the supported workflows, failure paths and the new regressions. Real B2 checks verified saved-login access, same-name merge, Keep both and same-size content updates. All disposable cloud files and retained versions created by those checks were removed. A repeated independent native B2 API read matched the app's storage byte total after cleanup settled.

Payment reminder dates and daily duplicate prevention use simulated dates in automated tests. Delivery remains subject to macOS notification permissions and Focus settings.
